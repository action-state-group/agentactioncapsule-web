The public log

The append-only transparency log, read live from the public witness (a SCITT Transparency Service): total entries, the latest signed checkpoint, how long it's been running, and the most recent records. It's early and small — that's the point of showing it honestly: it's public, so anyone can read it and verify any entry, and it only grows. Records carry a payload hash, never your data.

Agent Action Capsule

An open, individual profile (an IETF Internet-Draft; not WG-adopted) built on the SCITT Architecture (RFC 9943), for verifiable records of agent actions. Stewarded today by Action State Group, built to be donated to a neutral home.
