Specifications

The Internet-Drafts this site documents, the test vectors for each, and the open-source code that implements them.

Every draft here is an individual Internet-Draft submitted for discussion: not adopted by a working group, and not a standard. Revision and status are read from the IETF Datatracker when the site is built (last read 2026-10-03 UTC), so this page is never ahead of what is posted. A draft that has not been posted is listed without a link or a revision.

Agent Action Capsule

An open, individual profile (an IETF Internet-Draft; not WG-adopted) built on the SCITT Architecture (RFC 9943), for verifiable records of agent actions. Stewarded today by Action State Group, built to be donated to a neutral home.
