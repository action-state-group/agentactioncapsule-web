  1. 1Hash each half of the payload in this browser.
    SHA-256 over the RFC 8785 (JCS) canonical bytes.
  2. 2Build the capsule and derive its capsule_id.
    The same code the verifier runs.
  3. 3Check the capsule against the profile's structural rules.
    The verifier's own check, run here before anything is sent.
  4. 4Register the capsule_id with a transparency log.
    One 64-character digest. Nothing else is sent.
  5. 5Make your link and open it in the verifier.
    The capsule rides after the #, which browsers never send to a server.

3 · demonstration records

    
How this page treats the public log

    
A transparency log is append-only: an entry registered here stays there. So this page labels what it makes and keeps it small.

    
Labelled as a demonstration

    
    
      
  • Every capsule made here names its operator demo:agentactioncapsule.org/playground. The demo: prefix marks a demonstration record, so nobody reads it as a record of a real organisation's agent.
    • 
      
  • Every action_id starts with demo-, and the sample payload is made up.
    • 
      
  • The log itself holds only the 64-character capsule_id. The label lives in the capsule, which stays with you and anyone you share the link with.
    • 
    

    
Size and rate limits

    
    
      
  • The payload is capped at 2,048 bytes. The page refuses a larger one before hashing.
    • 
      
  • This page registers at most one capsule every 20 seconds, and at most 5 per browser tab session. These limits are enforced in your browser. They are a courtesy to the log, not a security boundary.
    • 
      
  • Registration sends only the digest, which is 64 hexadecimal characters whatever the payload's size.
    • 
    

    
Self-attested, then witnessed

    
A capsule made here has no producer signature: a browser demonstration holds no producer key. Its capsule_id recomputes from its own bytes, so any change to the record shows. On its own it is self-attested: only its maker vouches for it. It is witnessed once a transparency log its maker does not run has registered it and returned a receipt that verifies. On this site, “witnessed” and “registered” name that same step. A witness vouches for when the digest was registered, never for what the record says. See the assurance ladder and witness anywhere.

  









  

    

      

         Agent Action Capsule
        
An open, individual profile (an IETF Internet-Draft; not WG-adopted) built on the SCITT Architecture (RFC 9943), for verifiable records of agent actions. Stewarded today by Action State Group, built to be donated to a neutral home.
