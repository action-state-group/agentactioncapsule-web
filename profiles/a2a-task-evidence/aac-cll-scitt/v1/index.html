AAC / CLL / SCITT record profile for A2A Task Evidence

This URI identifies the base record profile referenced by the A2A Verifiable Task Evidence Extension proposal: recordProfile: "https://agentactioncapsule.org/profiles/a2a-task-evidence/aac-cll-scitt/v1".

What this profile is

The base profile binds one path from a Task Evidence payload to external registration: a Canonical Payload Binding (CPB)–derived evidence ID, an Agent Action Capsule (AAC) Producer Envelope over that ID, inclusion in a signed Checkpointed Local Log (CLL) checkpoint, and registration of that checkpoint as a SCITT Signed Statement with a Transparency Service Receipt. An optional checkpoint-aware witness adds a separate continuity assertion.

The normative definition — the evidence graph, the eight distinct bundle objects, the immutable core manifest, and the verification-result properties this profile populates — lives in the extension proposal itself and is not duplicated here:

Status

This is a provisional identifier for an independent proposal (v3.2, 2026-09-26). The base evidence graph this profile names is unchanged from v3.1; v3.2 adds interrupted-state and Traceability rules to the Task Evidence payload, described in the proposal. It is not yet a durable published specification; before deployment, this URI must identify one, per the parent proposal's discovery section.

Agent Action Capsule

An open, individual profile (an IETF Internet-Draft; not WG-adopted) built on the SCITT Architecture (RFC 9943), for verifiable records of agent actions. Stewarded today by Action State Group, built to be donated to a neutral home.
